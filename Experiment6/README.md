- Discount

- Region  

The goal is to optimize business strategy using multivariate visualization techniques.

---

## 🛠 Tools Used  

- R Programming Language  
- ggplot2  
- GGally  
- dplyr  
- Dataset: `6.retail_business.csv`  

---

## 📊 In-Lab Tasks  

- Create Parallel Coordinate Plots  
- Generate Bubble Charts  
- Implement Trellis Displays (Faceting by Region)  

---

## 📈 Visualizations Implemented  

### 1️⃣ Parallel Coordinate Plot  

- Compared Sales, Profit, and Discount simultaneously  
- Grouped by Customer Segment  
- Used normalized scaling for fair comparison  

### 2️⃣ Bubble Chart  

- X-axis: Sales  
- Y-axis: Profit  
- Bubble Size: Discount  
- Color: Region  

### 3️⃣ Trellis Display (Faceting)  

- Sales vs Profit plotted  
- Faceted by Region  
- Linear regression trend lines added  

---

## 🔍 Key Insights  

- Higher discounts generally reduce profit (inverse correlation observed).  
- Region significantly influences Sales–Profit relationships.  
- Customer segments show different performance trends.  
- Normalization improves interpretability in parallel coordinate plots.  

---

## ⚠ Limitations Observed  

- Overplotting in dense datasets  
- Bubble size perception is less accurate than axis position  
- Cognitive load increases with more than 3–4 variables
