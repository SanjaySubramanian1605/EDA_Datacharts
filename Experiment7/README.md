## 📌 *Objective*
*To implement different over-plotting reduction techniques in R to improve visualization clarity in large-scale datasets.*

---

## 🏫 *Scenario*
*A social media analytics team analyzes user engagement data (Likes and Comments). Due to a large number of data points, scatter plots become cluttered. Different visualization techniques are applied to reduce over-plotting and improve readability.*

---

## 📂 *Dataset*
*File Name:* 7.social_media_interactions.csv  

### *Attributes:*
- Platform  
- Likes  
- Comments  
- Shares  
- Post_Type  

---

## 🛠️ *Tools & Libraries Used*
- *R Programming Language*  
- *ggplot2*  

---

## 🧪 *In-Lab Tasks Performed*
- Loaded required R library (*ggplot2*)  
- Imported dataset using `read.csv()`  
- Created normal scatter plot  
- Applied Alpha Blending technique  
- Applied Jittering technique  
- Performed Aggregation  
- Generated 2D Binning plot  

---

## 📊 *Visualizations*
- *Scatter Plot* (Over-plotting demonstration)  
- *Alpha Blending Plot*  
- *Jitter Plot*  
- *Aggregated Engagement Plot*  
- *2D Binning Plot*  

---

## 📈 *Outcome*
*The applied techniques successfully reduced visual clutter and improved visualization clarity in dense datasets.*
