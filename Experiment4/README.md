## 🚦 Scenario  

A city traffic department analyzes accident data to identify:

- High-risk zones  
- Accident severity patterns  
- Accident frequency  
- Accident type distribution  

The goal is to use perceptually effective visualization techniques in R.

---

## 🛠 Tools Used  

- R Programming Language  
- ggplot2  
- dplyr  
- Dataset: `4.traffic_accidents.csv`  

---

## 📊 In-Lab Tasks  

### 1️⃣ Encode Severity Using Color Gradients  

- Converted severity into numeric values  
- Applied color gradient (Yellow → Red)  
- Higher severity represented using darker red  

---

### 2️⃣ Represent Accident Frequency Using Size  

- Counted accidents per location  
- Used point size to represent frequency  
- Larger points indicate higher accident occurrence  

---

### 3️⃣ Use Shape to Indicate Accident Type  

- Used different shapes for different accident types  
- Maintained clear labeling and minimal theme
