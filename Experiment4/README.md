📊 In-Lab Tasks
1️⃣ Encode Severity Using Color Gradient

Converted categorical severity into numeric values.

Applied color gradient (Yellow → Red).

Higher severity represented using darker red tones.

📌 Concept Used:
Color intensity to represent risk levels.

2️⃣ Represent Accident Frequency Using Size

Counted accidents per location.

Used point size to represent frequency.

Larger points indicate higher accident occurrence.

📌 Concept Used:
Size encoding for magnitude comparison.

3️⃣ Use Shape to Indicate Accident Type

Used different shapes for different accident types.

Maintained black color to avoid visual confusion.

📌 Concept Used:
Shape encoding for categorical differentiation.
